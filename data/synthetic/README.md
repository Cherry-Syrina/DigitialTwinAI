# Synthetic dataset

Generated by `../scripts/generate_data.py` (deterministic, seed **42**).

> **SYNTHETIC DATA** — generated by GlucoTwin AI's deterministic generator for software
> demonstration only. These records do NOT represent real patients, real clinical measurements, or
> medically validated values.

## Files

- `patient_profiles.csv` — 8 fictional patients (GT-001 … GT-008): demographics, diabetes type,
  years since diagnosis, HbA1c, BMI, activity level.
- `ehr_records.csv` — EHR-like encounters per patient (36 records): visit type, department,
  clinician type, complaints, findings.
- `glucose_summaries.csv` — latest HbA1c / hypo / hyper summary per patient.
- `sensor_readings.csv` — 16,128 five-minute readings (7 days × 288/day × 8 patients): glucose,
  insulin, carbs, steps, heart rate, sleep, meal events. Missing glucose (~170) and heart-rate
  (~170) values are injected to exercise the pipeline's robustness.
- `manifest.json` — regeneration metadata, seed, row counts, and this disclaimer.
